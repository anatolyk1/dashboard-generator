Privacidade e tratamento dos arquivos

O que acontece com o seu arquivo

O arquivo que você envia é lido e analisado na memória do servidor apenas o tempo necessário para montar o dashboard. Ele não é gravado em disco, não é salvo em banco de dados e não é compartilhado com terceiros. Depois que o dashboard é exibido, o servidor não guarda cópia do conteúdo.

O dashboard e o botão “Salvar em HTML”

O dashboard existe apenas na sua tela. Ao salvar em HTML, o arquivo é gerado no seu próprio navegador e baixado para o seu computador — ele contém os dados do seu arquivo, então guarde e compartilhe com o mesmo cuidado.

Dados técnicos

Como qualquer site, o provedor de hospedagem registra dados técnicos de acesso (endereço IP, data e hora e endereço acessado) por segurança e para evitar abuso. Esses registros não incluem o conteúdo dos arquivos. O sistema usa um único cookie, necessário para manter o seu acesso liberado após digitar o código de licença.

Boas práticas

Evite enviar documentos com dados sensíveis de terceiros (como CPF, dados de saúde ou senhas) se não for necessário para a análise. Se precisar tratar dados pessoais de outras pessoas, você continua sendo o responsável por esses dados perante a LGPD.
